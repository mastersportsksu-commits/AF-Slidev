# مشروع Slidev: معايير أنسنة المدن بالرياضة

مشروع Slidev حقيقي من ملف Word الأصلي، بعدد **45 شريحة**. يحافظ على نصوص المستند والجداول، بما فيها التكرار الموجود في الملف المدمج للنماذج 7–12. لم تتم إضافة بيانات بحثية جديدة.

## التشغيل أونلاين عبر GitHub وStackBlitz
1. افتح GitHub وأنشئ مستودعًا جديدًا (New repository).
2. ارفع ملفات ومجلدات هذا المشروع من داخل ZIP إلى جذر المستودع (`slides.md`, `style.css`, `package.json`). لا ترفع ZIP فقط.
3. افتح الرابط: `https://stackblitz.com/github/USERNAME/REPOSITORY` بعد استبدال القيم باسم حسابك ومستودعك، أو استخدم خيار استيراد GitHub داخل StackBlitz.
4. سيحمّل StackBlitz الاعتمادات. افتح Terminal واكتب `npm run dev` عند الحاجة، ثم Preview على المنفذ 3030.
5. عدّل الشرائح من الملف `slides.md`، والتصميم من `style.css`.

## التشغيل على Mac
يتطلب Node.js 22.12 أو أحدث.
```bash
npm install
npm run dev
```

## ملاحظة
- الجداول الكبيرة موزعة على شرائح متتالية حفاظًا على القراءة، ومحتوى كل خلية محفوظ.
- الشرائح مولدة من الملف الأصلي. لا تتضمن نسبًا أو معلومات من خارج الملف.
- خط Tajawal يُحمَّل من Google Fonts؛ عند عدم توفر الشبكة يظهر خط احتياطي.
- لا يمكن تأكيد مظهر StackBlitz النهائي إلا بعد تثبيت الاعتمادات وتشغيل المشروع هناك.
